🧪 Admin APIs Test

Test all admin get APIs to ensure they're working correctly.

📋 Available Admin APIs

  • GET /api/admin/:id - Get single admin by ID
  • GET /api/admin/list - Get all admins with pagination
  • GET /api/admin/stats - Get admin statistics

1️⃣ Get Single Admin by ID

GET http://localhost:5000/api/admin/68c563623a278f13e1975998

2️⃣ Get All Admins List

GET http://localhost:5000/api/admin/list

3️⃣ Get Admin Statistics

GET http://localhost:5000/api/admin/stats

4️⃣ Get Admins with Query Parameters

GET http://localhost:5000/api/admin/list?page=1&limit=5&is_active=true
